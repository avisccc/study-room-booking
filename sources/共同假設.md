# 共同假設

## 技術

| 項目 | 決定 | 說明 |
|---|---|---|
| 語言 | TypeScript | 型別檢查能抓到 AI 寫錯的地方 |
| 前端 / 後端框架 | Next.js(前後端同一個專案)+ Tailwind CSS | 不用分開寫前端和後端;Tailwind 做手機版版面比較快 |
| 資料庫 | PostgreSQL(Neon 免費方案)+ Prisma | Prisma 的資料表定義可以直接對照 UML 類別圖 |
| 登入 | **不做真的登入**,用簡單的身分切換代替:進網站時輸入學號(學生)或選「館員」,不用密碼。這也是需求:瀑布組寫進 SRS,敏捷組寫成 story | |
| 部署 | Vercel(免費方案) | 連 GitHub 後,merge 到 main 就自動部署 |
| 兩組怎麼分開 | 同一個 repo,Vercel 建兩個專案,Root Directory 分別設成 `waterfall/app`、`agile/app`;資料庫也各一個 | 兩組各一個網址,資料不會互相影響 |
| 未到場判定 | 不用排程,有人查詢或報到時才檢查:超過報到寬限還沒報到的預約,就標成未到場並記點 | 免費方案的排程功能有限,這樣做最簡單 |
